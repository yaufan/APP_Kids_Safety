# 安全小隊的聲音

所有聲音都是用程式合成的（numpy）：沒有錄音、沒有下載別人的素材，六首曲子都是為這個 APP 新寫的。給 3～6 歲的小朋友：輕快、清楚，**不嚇人**——警笛和消防鈴小小聲、遠遠的、很短；地震的隆隆聲低低的、很輕。

做的時候沒辦法用耳朵聽，是看數字（長度、音量、接頭）檢查的；請在手機上聽聽看，覺得哪個不像、不好聽再改。

## 怎麼產生
```
python3 design/sounds/make_sounds.py                 # 寫到 app/assets/sounds/*.wav
python3 design/sounds/make_sounds.py chirp click     # 只重做這幾個
python3 design/sounds/make_sounds.py preview 試聽.m4a  # 全部連在一起的試聽檔（要 ffmpeg）
```
- 亂數用固定的種子（照聲音的名字），每次跑出來的檔案都一模一樣。
- 程式會檢查：音效不超過 2.5 秒、不會太大聲、背景音樂 12～30 秒、資料夾裡沒有別的檔案、全部不超過 9 MB。
- 格式：WAV、單聲道、16 位元；背景音樂 16,000 Hz（頭尾接得起來，可以一直循環），音效 22,050 Hz。

## 背景音樂
| 檔案 | 用在哪裡 | 聽起來 |
|---|---|---|
| `music_base` | 小隊基地、安全帽頁 | 輕快的小隊主題曲，鐘琴＋輕輕的鼓，C 大調，每分鐘 112 拍 |
| `music_road` | 馬路世界 | 木琴，輕快，G 大調，120 拍 |
| `music_rescue` | 救災世界 | 沉穩、不緊張，柔和的銅管，F 大調，92 拍 |
| `music_body` | 身體世界 | 溫柔的卡林巴（拇指琴），D 大調，76 拍 |
| `music_home` | 家裡世界 | 像在家的鋼琴，有一點搖擺，C 大調，96 拍 |
| `music_rest` | 休息時間 | 最慢最輕的鐘琴，60 拍 |

## 音效
| 檔案 | 什麼時候 | 聲音 |
|---|---|---|
| `chirp` | 紅綠燈變綠 | 台灣行人燈的「布穀、布穀」鳥叫 |
| `car_pass`、`car_hum` | 車子經過、車子來了 | 輕輕的「咻～」和低低的引擎聲 |
| `brake`、`horn` | 車子停下來、司機揮手 | 很短的「嘶」（不尖）、友善的「叭叭」 |
| `whistle` | 走失時站好 | 汪汪警察的哨子 |
| `steps` | 走過馬路、走樓梯 | 四步腳步聲 |
| `click`、`buckle` | 安全帶扣好、安全帽扣環 | 「喀」 |
| `rumble` | 地震 | 很輕的低低隆隆聲和幾下小小的碰撞 |
| `water`、`window`、`wind`、`switch` | 濕毛巾、關窗、颱風的風、手電筒 | 水聲、窗戶「喀」、風聲、開關 |
| `siren`、`bell` | 說「我家」、消防 | 遠遠的、小小聲的警笛和消防鈴 |
| `key_0`～`key_9`、`ring` | 數字鍵盤（119、爸媽的電話）、電話通了 | 電話按鍵音、兩聲鈴響 |
| `no`、`fill` | 說「不要！」、按住的時候 | 堅定友善的兩下鼓、慢慢升高的音 |
| `found`、`right`、`try`、`cheer` | 找到危險、答對、再試一次、做完一關 | 木琴三個音往上、兩個鐘聲、輕輕的「嗯？」（不是錯誤的嗶聲）、四個音往上 |
| `badge` | 徽章貼到安全帽上 | 「噹」 |
| `tap`、`pop`、`whoosh`、`page`、`night` | 按鈕、拿起東西、漫畫字、換頁、休息 | 小小的介面聲 |
