# 安全小隊

給 **3～6 歲**的小朋友，在台灣，國語為主：學安全。小朋友自己當戴安全帽的小隊員，三個幫手（汪汪警察、喵喵消防員、兔兔護士）。

- 設計：[docs/design.md](docs/design.md)，草圖在 `docs/mockups/`。
