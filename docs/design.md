# 設計：安全小隊

> 給 3～6 歲小朋友的安全教育遊戲。2026-11-15 定案（見最後「已經決定的事」）。草圖在 `docs/mockups/`。和「畫畫小鎮」「字母寵物」「動物小餐廳」「小卡認天下」「想一想樂園」「眼尖尖大挑戰」「迷宮小冒險」「小小生活家」是同一個作者的兄弟 APP，同一套技術，畫風不同。

## 一句話
小朋友戴上黃色安全帽當「小隊員」，跟著三位動物幫手走過四個世界：過馬路、地震火災颱風、身體紅綠燈、家裡找危險。每一關都是「看一看、想一想、自己做做看」，做完把練習帶回真的生活（下次過馬路一起做一次）。目的是把安全的事變成小朋友自己會做的動作，不是嚇小朋友。

## 給誰
- **3～6 歲**，在台灣，國語為主。幼兒園的小朋友和家長。
- 為什麼做這個：台灣 0～14 歲的小朋友，2025 年平均**每天約 34 位**因為交通事故受傷或過世（靖娟兒童安全文教基金會）。教育部有《幼兒園防災參考指引》（地震「趴、掩、穩」，火災低姿勢、濕毛巾、不搭電梯，颱風、水災），交通安全有「集、轉、探、避、揮」的過馬路口訣，可是現有的教材幾乎都是給小學生的，幼兒園的「身體界線」教材更少（台北市 114 學年才開始發桌遊）。研究顯示，5 歲小朋友只要練 5 天就能明顯學會保護自己的動作（泰國的實驗），所以重點是**短短的、每天可以練一下**。
- 兩個難度：**小小**（3～4 歲）幫手先示範、一次一步、該點的地方會發亮；**大**（5～6 歲）自己把整串步驟做完、順序要對、還要回答「為什麼」（兩張圖選一張）、背爸媽的電話。
- 不連網、不定位、沒有廣告、沒有帳號、不要任何權限（和兄弟 APP 一樣）。**沒有麥克風**，所以「大聲說不要」是用一個大按鈕代替。

## 練什麼
- **過馬路**：紅燈停、小綠人走、小綠人跑很快就不要走；過馬路五步「集、轉、探、避、揮」；牽大人的手；不在車子旁邊跑；坐車繫安全帶、坐安全座椅；坐機車戴安全帽。
- **地震、火災、颱風**：地震「趴、掩、穩」，搖完再跟大人走到空曠的地方；火災低姿勢、濕毛巾、走樓梯不搭電梯、到外面打 119；颱風待在家、關窗、陽台的東西收進來、準備手電筒。
- **身體紅綠燈**：泳衣遮住的地方是自己的，別人不可以看、不可以摸；不舒服就說「不要！」；要告訴信任的大人；好的秘密和不好的秘密。
- **家裡安全**：熱的鍋子、插座、藥、陽台、菜刀、熱水、小東西不放嘴巴，找出來、把它弄安全。
- **走失怎麼辦**：站在原地、找穿制服的人、說自己的名字和爸媽的電話（家長在家長模式輸入電話，小朋友練習背）。
- 做法照研究說的：**自己動手想**（不是看影片）、一個畫面只有少少幾個可以點的地方、**結果就是回饋**（車子停下來、小朋友安全了，不是給星星）、每關結束有**問家長的問題**（親子一起玩）、每關很短、最後**帶回真實生活**（「下次過馬路我們一起做做看」）。**絕對不嚇人**：沒有血、沒有燒到人的火、地震只是晃一晃不會倒、幫手說話平平穩穩，像在說「本來就要這樣做」。

## 小隊：三位幫手和小隊員
- **小隊員**就是小朋友自己：戴黃色安全帽、穿反光背心的小人。第一次打開選髮型（4 種）、膚色（4 種）、安全帽的顏色（6 種）。家長可以輸入名字（也可以不打，叫「小隊員」）。
- **汪汪警察**（小狗，藍制服、白手套）：帶**馬路世界**。吹哨子，會比「停」的手勢。
- **喵喵消防員**（小貓，紅色消防衣、黃帽）：帶**救災世界**。冷靜、動作慢慢的。
- **兔兔護士**（小兔，白衣、粉紅十字）：帶**身體世界**和**家裡世界**。溫柔，會問「你覺得呢？」。
- 幫手只有示範和說話，**做的人是小隊員**：地震是小朋友把小隊員拖到桌子下，不是看小貓躲。

## 畫面
手機直的拿，一個畫面只有一件事。
1. **小隊基地**（首頁）：上面是小隊員和他的安全帽（徽章貼在帽子上），中間四個世界的大牌子（像路牌：藍圓形＝馬路、紅方形＝救災、綠圓形＝身體、黃菱形＝家裡），點了就進去。右下角小小的家長按鈕（要過家長關卡）。
2. **世界頁**：一條路，上面排著這個世界的關卡（路牌形狀的卡片），做過的有徽章，下一關會跳一跳。幫手站在旁邊說這一關要做什麼。
3. **關卡**：上半是情境（馬路、房間、客廳），下面是幫手的對話框（念出來）。可以點的地方發亮（小小）或不發亮（大）。做對了畫面本身會回應（車子停下來、燈變綠、桌子蓋住小隊員）。
4. **做完的那一頁**：幫手說「做得好」＋一張**給家長的問題卡**（「問問小朋友：我們家最近的馬路，紅綠燈在哪裡？」）＋一句**回真實生活**（「下次出門，我們一起做一次」），然後徽章貼到安全帽上。
5. **安全帽頁**（安全小勇士）：安全帽和背心上的徽章，每個世界一個隊徽。
6. **休息頁**：時間到了，幫手們回基地休息，安全帽掛起來。
7. **家長模式**：見下面。

## 玩法：四個世界
每一關 1～3 分鐘，做法都是「幫手說一句 → 小隊員做 → 畫面回應 → 幫手說為什麼 → 家長問題 → 回真實生活」。「大」難度多一個「為什麼」：兩張圖選一張（例如「為什麼要牽手？」：車子看不到小小的人 ／ 因為手冷）。

### 馬路世界（汪汪警察）
| 關卡 | 怎麼玩 | 學到 |
|---|---|---|
| 紅綠燈 | 路口的行人燈（台灣的小綠人、紅色站立的小紅人、倒數數字）。紅燈時點小隊員他只會搖頭「紅燈，等一下」；綠燈亮、布穀聲響，點了才走。小綠人**跑很快**（快變紅）的時候點，汪汪說「小綠人在跑，表示來不及了，等下一次」。車子看到紅燈會停。 | 紅燈停、綠燈行、快變紅不要衝 |
| 過馬路五步 | 「集、轉、探、避、揮」變成五個大按鈕，照順序點：**集**（停在路邊，腳在線後面）、**轉**（點左邊看、點右邊看，頭會轉）、**探**（慢慢探頭看有沒有車）、**避**（一台車來了，點「等」讓它過去）、**揮**（對司機揮手，司機揮回來、車子停）。五個字大大的寫出來，幫手念白話；做完五個字排成一排發亮。小小：一次亮一個；大：自己照順序，點錯順序汪汪搖頭「先⋯⋯」。 | 教育部口訣，家長和幼兒園都認得 |
| 牽手走 | 出門畫面：點誰的手？（媽媽的手、氣球、小狗繩）牽到媽媽的手才出發；路上有停車場，球滾到車子旁邊，兩個選擇：跑去撿 ／ 跟媽媽說。選跑去撿，汪汪攔住：「車子旁邊看不到你喔」，再選一次。 | 牽手、不在車旁跑、先跟大人說 |
| 坐車 | 車子裡：把安全帶拖到扣子「喀」，安全座椅；把手伸出窗外的小動物，點它，手收回來。機車：把安全帽拖到頭上、點扣環「喀」。 | 安全帶、安全帽 |
| 走失了怎麼辦 | 夜市（台灣的場景）人很多，媽媽不見了。三步：**站在原地**（點小隊員，他站好不亂跑）→ **找穿制服的人**（畫面裡有店員、警察、帶小孩的媽媽、一個普通路人；點對的）→ **說名字和電話**：大大的數字鍵盤，家長在家長模式輸入的電話一個數字一個數字發亮，小朋友照著點，APP 念出來；最後一個大按鈕「大聲說一次」，小朋友對著手機說，APP 不錄音，只是給他一個說的時間。大：數字不發亮，自己按。 | 站在原地、找誰、背電話 |

### 救災世界（喵喵消防員）
| 關卡 | 怎麼玩 | 學到 |
|---|---|---|
| 地震 | 客廳，畫面輕輕晃、燈輕輕搖（不會倒）。喵喵：「地震！趴、掩、穩」。**趴**：把小隊員拖到桌子下；**掩**：點頭，雙手（或抱枕）蓋住頭；**穩**：按住桌腳不放手，圈圈慢慢轉滿，搖晃停了才放開。然後跟大人走樓梯到外面空曠的地方（電梯的按鈕按了喵喵會說「地震不搭電梯」）。大：多一題「哪裡不能躲？」（窗戶旁邊、書櫃旁邊、桌子下）。 | 趴掩穩、不搭電梯 |
| 火災 | 房間，上面有淡淡的灰煙（不畫火燒東西）。**低姿勢**：把小隊員沿著地板拖到門口（站起來的話煙會碰到頭，幫手說「蹲低低」）；**濕毛巾**：把毛巾拖到水龍頭、再拖到嘴巴；**走樓梯**：兩個門選一個（樓梯 ／ 電梯）；到外面後**打 119**：三個大大的數字鍵，照順序按 1、1、9，電話接通，喵喵在電話那頭問「哪裡失火了？」，小隊員說「我家」（按鈕）。還有：不躲衣櫃、不躲床下、不回去拿玩具。 | 低姿勢、濕毛巾、樓梯、119 |
| 颱風 | 窗外風雨（溫和的動畫）。點窗戶關起來、把陽台的盆栽和衣服拖進來、點手電筒放在桌上、把拖鞋放好。喵喵：「颱風天待在家裡最安全，不去海邊看浪」。順便：停電了，點手電筒。 | 颱風天在家、關窗、手電筒 |
| 演練（以後） | 家長按「演練」，APP 播小小聲的隆隆聲，小朋友在真的家裡做趴掩穩，家長點「做到了」。 | 把練習帶回家 |

### 身體世界（兔兔護士）
這個世界**預設打開**，家長模式可以關掉。第一次進去，先出現一頁**給家長看的話**：要教什麼、怎麼一起玩、可以在家長模式關掉；家長按「我看過了」才開始。全部的畫面都是平平靜靜的，沒有壞人、沒有可怕的情境。**0.1 先做前兩關**（身體紅綠燈、說「不要！」），後兩關放 0.2。
| 關卡 | 怎麼玩 | 學到 |
|---|---|---|
| 身體紅綠燈 | 一個穿泳衣的小人（就是小隊員）。點身體的地方，亮綠燈、黃燈或紅燈：**綠**（手、頭、肩膀：握手、擊掌、拍拍肩膀可以）、**黃**（臉、肚子：要先問我）、**紅**（泳衣遮住的地方：是我自己的，別人不可以看、不可以摸；爸媽幫忙洗澡、醫生看病而且爸媽在旁邊，才可以）。兔兔用「紅綠燈」說，不用難的字。小小：點了聽就好；大：換兔兔問「這裡是什麼燈？」小朋友選。 | 泳衣遮住的地方是私密的 |
| 說「不要！」 | 三個小情境（都是平常的事）：有人要抱、要搔癢、要親臉，小隊員不想要。畫面中間一個大大的紅色「不要！」按鈕，**按住**它，聲音條慢慢變滿，小隊員挺胸把手伸出去「不要！」，對方就停下來退後、說「好」。兔兔：「你的身體你決定，不管是誰都可以說不要。」也有一次反過來：小狗不想被抱，小隊員要停下來。最後兔兔指著家長選的安全大人：「不舒服的事，要去跟他們說。」 | 說不要、也尊重別人的不要 |
| 告訴信任的大人（0.2） | 家長在家長模式選 2～4 個「安全大人」（媽媽、爸爸、阿嬤、老師⋯⋯用圖示＋名字）。兔兔：「有不舒服的事、怪怪的事，就去跟他們說，不是你的錯。」小情境：有人說「這是秘密，不可以跟爸媽說」→ 兔兔：「讓你不舒服的秘密，更要說。」生日禮物的驚喜秘密可以留著。 | 跟誰說、秘密的分別 |
| 和爸媽一起（0.2） | 一頁親子共玩：五個問題（「如果有人摸你覺得怪怪的，你會跟誰說？」）、一起說一次「我的身體我自己決定」、拍手約定。 | 家長知道怎麼接 |

### 家裡世界（兔兔護士）
每個房間一張圖，裡面藏 3～5 個危險的東西，**找出來、弄安全**：
| 房間 | 危險 → 怎麼弄安全 |
|---|---|
| 廚房 | 熱鍋把手朝外 → 轉進去；菜刀在桌邊 → 拖進抽屜；熱水壺線垂下來 → 推進去；地上的塑膠袋 → 收起來 |
| 客廳 | 插座 → 蓋上插座蓋；桌上的藥（看起來像糖果）→ 拖到高櫃子；小硬幣和鈕扣 → 放進盒子；窗邊的椅子 → 移開 |
| 浴室 | 浴缸滿滿的水 → 拔塞子；地上濕 → 鋪防滑墊；熱水 → 先點冷水再點熱水試溫 |
| 陽台 | 欄杆旁邊的椅子和箱子 → 搬走；窗戶打開 → 關好 |
小小：一次亮一個、2～3 個；大：5 個都自己找，而且每個要回答「為什麼」（兩張圖）。找完兔兔問家長：「我們家的插座有蓋子嗎？去看看。」

## 獎勵：安全帽上的徽章（沒有分數）
- 每做完一關，一枚小徽章貼到安全帽或背心上（路牌形狀：紅綠燈、桌子、119、綠燈人⋯⋯）。
- 一個世界全部做完，拿到那位幫手的**隊徽**（汪汪的警徽、喵喵的消防徽、兔兔的十字徽），幫手敬禮。
- **真實生活徽章**（金色）：家長在家長模式點「我們真的在馬路上做過了」「家裡演練過地震了」，小朋友拿到金徽章。這個最重要。
- 沒有星星、沒有分數、沒有排名、沒有倒數；點錯只會「再試一次」。

## 每次玩多久
- 家長設定，**預設 15 分鐘**（和兄弟 APP 一樣）。時間到了幫手們回基地休息、安全帽掛起來，APP 說「換你去真的地方做做看！」，要家長解開或等一個小時才能再玩。每一關本來就短，一次玩 2～4 關剛好。

## 家長模式（要過家長關卡）
- 小隊員的名字、樣子；年齡（難度）；每次玩多久。
- **爸媽的電話**（走失那關用來練習背；只存在手機裡）和**小朋友怎麼叫他**（媽媽、爸爸、阿嬤⋯⋯，念成「我媽媽的電話是⋯⋯」）。**不存地址、不存爸媽的全名。**
- **安全大人**：選 2～4 個，圖示＋稱呼（「說不要」那關最後會出現）。
- 要開哪些世界；**身體世界可以關掉**（預設開，第一次進去會先給家長看說明）。
- 進度：每個世界做了哪幾關、練了幾次；**真實生活清單**（在真的路口做過、家裡演練過、看過家裡的插座），打勾就給金徽章。
- 給家長的小抄：每關的口訣和可以問的問題（可以念給小朋友聽）。
- 聲音、念出來。
- 以後的完整版購買只在這裡。

## 畫風：漫畫網點風（2026-11-15 決定，草圖見 `docs/mockups/`）
像漫畫書：顏色平塗、**深藍色的細外框**（`#1E3A6E`，不是黑色）、陰影用一顆一顆的**網點**、動作有**速度線**、聲音有**漫畫字**（布穀！晃晃～找到了！）、幫手說話用白色的**對話框**。標題字白色加深藍色邊。最有活力、最像「小隊出任務」，每個動作都能配一個漫畫字和音效，回饋很清楚；安全的事用漫畫的節奏說，輕鬆不嚇人。和畫畫小鎮的粗黑框貼紙不一樣：這裡的線**細很多、是深藍色**，而且有網點和漫畫效果。只做這一種。

候選（沒選）：瓦楞紙箱手作風、絨毛布偶風；第一輪的標誌圖示風、拼布刺繡風、馬賽克磁磚風（`0_畫風選擇.png` 留著第二輪三種的比較）。

**怎麼畫（flutter_svg 不支援 `<pattern>`、`<mask>`、`<filter>`，所以一個都不用）**：
- **形狀**：Python 用 shapely 算每樣東西的形狀，寫成 `<path>` 平塗顏色。白色、很淺的東西和**皮膚**不加網點（臉上有點點像髒髒的）。
- **網點**：在 Python 裡算好，寫成**真的小圓**。每個形狀只在「陰影那一邊」加網點：形狀減掉往左上移 10～12 點的自己，剩下右下的一條月牙形就是陰影區。在陰影區裡排一個轉 30 度的格子（間距 5～6 點），每一點的半徑從月牙內緣的 0 漸漸變大到邊上的約 1.4 點（取代漸層遮罩的效果），半徑小於 0.4 的不畫。一個形狀的所有網點合成**一個 `<path>`**（每個圓寫成 `M x-r,y a r,r 0 1,0 2r,0 a r,r 0 1,0 -2r,0`，座標取到小數 1 位），顏色是底色加深 45%（不是黑色），用 `fill-opacity`；外面包一個 `<clipPath>`（裡面就是那個形狀，flutter_svg 支援），邊上半顆的點就被切乾淨。
- **檔案大小**：每個 SVG 控制在 **70 KB 以下**。天空、牆、地板這種大面積背景不加網點，或只在下緣加一條疏一點（間距 8 點）的網點帶；`build.py` 檢查每個檔案的大小，超過就自動把網點間距加大再算一次。一個角色大約 300～600 顆點（約 15～30 KB）。
- **深藍外框**：同一個形狀的 path 再畫一次，`fill="none" stroke="#1E3A6E" stroke-linejoin="round"`，畫在網點上面蓋住點的邊。線寬在手機上固定約 1.8 點：Python 依照這張圖在畫面上的大小換算（圖畫得大，線就寫細一點），所以大圖小圖的線一樣粗。手腳、柱子這種粗線，用兩條線疊：底下深藍粗一點，上面顏色細一點，邊就有外框。
- **速度線**：幾條平行的深藍短線（`<path>` 的 `stroke`、`stroke-linecap="round"`），長短交錯，放在東西動的反方向；做成獨立的小 SVG，由 Flutter 控制出現和淡出。
- **漫畫字**：鋸齒形的爆炸框是一個 16 個角的多邊形（白或黃底、深藍框），也是獨立的小 SVG；**裡面的字由 Flutter 用我們的字型畫**（Text 加深藍描邊），不放在 SVG 裡（flutter_svg 的文字不穩，而且字要跟著語言變）。
- **對話框**：白底深藍框，尾巴指向說話的幫手，用 Flutter 的 `CustomPainter` 或一個可以拉長的 SVG 畫；字一樣由 Flutter 畫。
- **亮光**：每個東西左上一道白色小亮光（圓角長條），讓平塗不會太平。
- 草圖（`docs/mockups/make_mockups.py`）為了快，網點是用 `<pattern>`＋`<mask>` 在瀏覽器裡畫的；APP 裡的圖照上面的做法，`fluttercheck` 用真的 flutter_svg 比對（和兄弟 APP 一樣）。
